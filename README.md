# LeadForge

AI-powered platform for finding businesses, analyzing websites, generating personalized outreach, tracking leads, and delivering modern websites.

## Goals

- Automate lead generation
- Generate website audits
- Create personalized outreach
- Manage clients
- Build websites
- Grow into a SaaS platform

## Tech Stack

- Next.js
- TailwindCSS
- Supabase
- n8n
- Gemini
- ChatGPT
- Vercel
